# dev_v58：第 10 轮新场景联合应力确认测试报告

## 1. 报告定位与评估范围

本报告为第 10 轮新场景确认评测，并非全十轮最终总结报告。本轮测试评估固定的 6 个策略模型在全新环境场景与一份事前冻结的联合应力下的表现，属于在同一组固定模型上进行的新场景确认（fresh-scene confirmation on the same six fixed models），而非启动独立的训练复现：这里不包含任何训练运行，因此结果不含训练方差，不能据此推断训练总体的可重复性。

评测输入严格限定为 v57 manifest 冻结选定的 6 个策略模型：3 个 v50 修正版纯存活名义训练对照组（选定阶段分别为 u200/u200/u100）与 3 个 v57 速度增广实验组（均为 u100）。所有策略模型权重均已冻结，不进行任何重新筛选或重新训练。原始训练均采用相同的初始权重与 614,400 步训练预算；各实验组与其配对对照组共享同一初始权重（`initial_policy_hash` 逐一相等）。

上游 v57 冻结清单 SHA-256 为 `ac3bcae513eb092d3d0a2f4cd2eafda01ff9f9ed019df80260022c0133b89ea7`。评估同时引入三套规则策略作为基准锚点：lead、safetop 与 HOLD。

## 2. 事前声明设计与场景扰动设定

评测设计在 v57 仍在运行、结果未知时完成事前声明，未因 v57 结果调整；完整准则、模型清单、具体场景与联合扰动数组均记录于本仓库公开的冻结清单文件（第 5 节）。本报告与冻结清单已具备公开自包含性，不依赖任何未公开文件。

测试选用 64 个基础世界种子（NumPy RNG 种子 `580102`，调试种子 `580101`）。每个场景对应两组测试条件：

1. 名义测试组：参数三元组固定为名义基准（鱼速度比例 1.0、捕食者转向角 0 度、捕食者速度比例 1.0）。
2. 联合测试组：由独立 RNG `580202` 为每个场景抽取一组事前冻结的联合扰动参数。

联合扰动空间由独立均匀分布构成：鱼速度比例取自 {0, 0.5, 1}，捕食者转向角取自 {0, 90, 180, 270} 度，捕食者速度比例取自 {0.75, 1, 1.25}。联合扰动参数在任何评分之前一次性抽好、冻结并写入清单，所有控制器共用同一场景的同一组参数。

64 个场景的实际抽样频次为：鱼速度比例（0 / 0.5 / 1.0）分别出现 23 / 17 / 24 次；转向角（0 / 90 / 180 / 270 度）分别出现 8 / 23 / 19 / 14 次；速度比例（0.75 / 1.0 / 1.25）分别出现 20 / 22 / 22 次。抽样中命中的 3 个全名义三元组按规则直接保留，未做重新抽取。

物理环境约束：仅在重置后修改速度向量。鱼群初始位置、存活状态、死亡时间戳、捕食者初始位置、时间步、pre-roll 轨迹与内部 RNG 序列完全一致；观测向量按新速度重新计算（观测不保持 bit-identical，而是与新的速度物理一致，且不引入额外通道）；重力与碰撞反弹逻辑保持不变。扰动本质属于有限离散的人工应力测试，并非自然环境域采样，也不是连续空间覆盖。

全量评估包含 9 个控制器 × 2 种条件 × 64 个场景 = 1,152 个 episode，由 4 个 worker 并行运行 2,279 秒（约 38 分钟）。统计分母统一为 96，第一步即死亡的情形不剔除、不扣减。

## 3. 评测结果与统计特征

各臂平均存活表现如下：

- 名义条件均值：对照组 0.93132，实验组 0.92866；差值（实验 − 对照）−0.00266，双侧 95% 置信区间 [−0.00787, +0.00250]，场景胜负平 25 / 37 / 2（共 64）。
- 联合扰动均值：对照组 0.88238，实验组 0.88558；差值（实验 − 对照）+0.00320，双侧 95% 置信区间 [−0.00244, +0.00949]，场景胜负平 32 / 26 / 6（共 64）。
- 各重复（replicate）差值细分：
  - 联合条件（实验 − 对照）：rep0 −0.00586，rep1 −0.01497，rep2 +0.03044。
  - 名义条件（实验 − 对照）：rep0 −0.01351，rep1 +0.00570，rep2 −0.00016。

统计推断采用场景配对 episode bootstrap（10,000 次重抽样，随机种子 `580301`）。重抽样将两个测试条件及全部 6 个模型绑定在同一基础场景单元内；置信区间衡量的是这 6 个固定模型面对场景扰动时的条件抽样不确定性，而不包含训练随机性。3 对训练模型的差异仅具描述性符号意义。

PPO 相对 HOLD 基线的增益变化：实验组名义 0.18142 → 联合 0.10482；对照组名义 0.18408 → 0.10162；交互项差值（实验 − 对照）+0.00586，95% CI [−0.00082, +0.01308]。规则基线：lead 名义 / 联合 0.9748 / 0.9548，safetop 0.9342 / 0.8896，HOLD 0.7472 / 0.7808。规则基线（lead 与 safetop）存活率明显高于强化学习策略，如实陈述；HOLD 为维持固定动作的基准，不等同于绝对静止。

## 4. 事前声明决策规则与判定结论

本轮严格执行未经修改的事前声明替换准则。只有同时满足以下四项条件时，才支持用速度增广替代名义训练基线：

1. 联合扰动下所有 3 个重复的均值差值全部为正：【不通过】（仅 rep2 为正，rep0 与 rep1 为负）。
2. 联合扰动聚合差值的 95% 置信区间下界大于 0：【不通过】（下界 −0.00244）。
3. 名义条件下的均值损失小于 0.01（1 个百分点）：【通过】（实际损失 0.00266 < 0.01）。
4. 名义条件差值的 95% 置信区间下界不低于 −0.02（−2 个百分点）：【通过】（实际下界 −0.00787 ≥ −0.02）。

综合判定：【未达标（FAIL）】。结论为维持名义训练基线作为默认方案。该结论仅为测试报告的决策建议，不涉及线上部署变更。

联合扰动的聚合区间覆盖 0，且重复间符号不一致，说明现有证据不足以支撑基线替换；这不等同于证明了速度增广没有作用、效应为零、差距无法弥合或机制无效。各重复间的符号差异仅反映这 3 组固定配对之间样本均值的描述性异质性，不能据此推断机制缺位。名义条件通过门槛属于固定的固定模型均值与置信区间在事前声明的工程容差内（名义损失 < 1 个百分点，且区间下界不低于 −2 个百分点），不能引申为各场景或各重复的绝对无损或非劣，区间包含 0 也不能证明统计等价。事前设定的 2 个百分点容忍度是工程标准，而非发现得到的统计常数。分析采用双侧 95% 分位数置信区间，而正下界准则是单向替换决策规则，不能表述为单侧检验结果。
