# 鱼群避障强化学习迭代复盘（v49–v58）

## 结论：保留世界，修正训练，继续诊断威胁响应

这个世界仍适合作为局部避险学习任务：鱼能通过观察威胁和改变动作提高存活率，无需先增加主动追击或鱼间碰撞。十轮实验中，最明确的训练改进来自修正观测、动作与奖励的身份对应，再使用仅含存活与死亡的奖励。初速随机化训练没有达到最后确认实验预先规定的替换门槛，继续保留标称初速训练配置。

手写规则在本轮比较中仍优于 PPO；规则使用相同的自身状态与可见威胁信息，没有隐藏的捕食者状态权限。它的优势机制尚未由这些实验隔离。

## 同场景前后对照与视频

补充评测用 RNG 种子 590102 生成同一批 64 个新场景，每局 96 条鱼、500 步。成绩是每局最终存活数除以 96，再跨场景平均，不是通关局数比例。

| 策略 | 平均最终存活率 | 每局平均活到最后的鱼 |
| --- | ---: | ---: |
| 旧版历史选定模型（v45） | **91.11%** | 87.47 / 96 |
| 新方案固定三模型均值（v50） | **93.72%** | 89.97 / 96 |
| 手写 `rule_flee_lead` | **96.97%** | 93.09 / 96 |

新方案较旧模型高 **2.61 个百分点**，场景配对 95% 区间为 [1.97, 3.24] 点，平均每局多活约 2.5 条鱼。旧方是一个历史选定 checkpoint，新方是三份固定模型分别运行的均值，不是集成控制器；输入维度分别为 18 与 11，物理初态相同。这是整套方法比较，不能归因于一个修复，区间也不包含重新训练的不确定性。

下表第2轮的 **+5.20 点**回答的是另一问题：同一修正训练流程下，原奖励与简化奖励有什么差别。它不等于这里旧代表模型到新方案的 +2.61 点，两组对照不应相加。

历史 89.9% 来自旧模型在旧 40 场景上的平均值；旧权重没有重训，在这批新场景中得到 91.11%。第10轮还使用了另一场景库和选定 checkpoint，不能把它的 93.13% 与此表串成提升曲线。[完整基准说明](../demos/before_after_202610/benchmark_explainer.md)

[观看 50 秒三栏视频](https://grapeot.github.io/fish_rl_ai_iteration/assets/before_after_202610.mp4)：旧模型、新模型 rep0、手写规则从同一初态同步运行。视频取预设场景库的第一个种子，单局终局分别为 87、94、93 条；该局新副本虽高于规则，规则在 64 局均值上仍领先。鱼之间无物理碰撞，会重叠，肉眼可分辨的蓝点数不等于存活数量。**单局视频不是总体成绩。**

## 世界为什么成立，以及它不包含什么

圆形场地中的鱼具有惯性、最大速度限制、每步 30° 转向及壁面阻尼反弹，每局 500 步、50 个仿真时间单位。捕食者受重力和反弹驱动，不主动追鱼；鱼之间没有物理碰撞。因此，这是对外生移动威胁的局部控制任务，群体外观本身不证明必要协作。

关键对照来自手写规则，而非 PPO：从 `rule_flee_lead` 运行到第 100 步的相同状态分支，继续规则的平均终局存活率为 **97.58%**，之后只保持滑行为 **76.17%**，屏蔽威胁信息但保留边界控制为 **84.61%**。后段控制和威胁信息确有价值。另一条固定目标区规则可在这些场景中避开后段损失，说明世界也允许地理性避险策略；不能据此推断所有轨迹永久安全。[前置反事实实验](v48/control_experiment.md)

## 训练问题与世界设定分开处理

旧训练包装器每步轮换被观察的鱼，将一个动作广播给全群，并返回群体平均奖励；评估却让每条鱼独立行动。修正后，每个训练 episode 固定焦点鱼，使观测、动作、自身奖励及死亡终止对应同一个体。关闭邻居特征后使用 11 维局部观测，仍是部分可观测问题，不宣称严格的观测状态 MDP。[第1轮](v49/dev_v49.md)

固定焦点基线中，其余鱼保持滑行，原密度奖励仍读取它们，存在训练与评估的奖励上下文差异。这是奖励设计的限制，不是另一个世界规则错误。第2轮把回报改为每个存活步 `+0.7`、死亡步 `−50`，同时删除距离、边界和密度塑形；该组合对照不能定位其中单项的贡献。[第2轮](v50/dev_v50.md)

## 十轮实验与决定

表中各项收益只在相应轮次的同场景对照内成立。不同轮次的场景库与选模阶段不同，不应把分数串成统一的提升曲线。

| 轮次 | 问题 | 结果与决定 |
| --- | --- | --- |
| [1 · v49](v49/dev_v49.md) | 固定身份后的 PPO 能否学习？ | 建立可用基线。同一报告集上，事后按 selection 选出的 checkpoint 均值为 0.9086，final 为 0.8865。环境种子流重叠、阶段标签早一轮及 report 先于 selection 的局限均保留记录。 |
| [2 · v50](v50/dev_v50.md) | 原奖励还是仅奖励存活/死亡？ | 修正连续随机流后，6 次同预算训练的选定模型报告均值 **0.8816→0.9336，+5.20 点**。采纳简化奖励。final 差距 21.73 点约 84.4% 来自一个原奖励 run，不能视为普遍收益。 |
| [3 · v51](v51/dev_v51.md) | 确定性动作还是随机采样？ | 六个冻结模型的采样差值三正三负，一个下降约 6.75 点；未见统一收益，保留确定性推理默认。 |
| [4 · v52](v52/current_baseline/dev_v52.md) | PPO 如何响应捕食者输入？ | 屏蔽全部捕食者输入，固定三 PPO 平均 **+0.720 点**，规则 **−20.286 点**。只屏蔽捕食者速度的 PPO 区间跨零。三模型的动作都会响应输入，不能称完全无视信息；响应也不等于获得生存收益。 |
| [5 · v53](v53/dev_v53.md) | 第 500 步终止归零还是超时 bootstrap？ | 改为终止归零，选定模型下降 **3.91 点**。当前无剩余时间输入的训练方案保留 timeout bootstrap；不据此否定有限时域目标定义，也未确认退化原因。 |
| [6 · v54](v54/dev_v54.md) | 鱼的初速度缩放为 ×1/×0.5/×0？ | 归零使 PPO **93.38%→88.39%**，相对 HOLD 优势 **17.93→1.83 点**。初速干预改变了动量、速度观测及初始控制能力；零速转向是空操作，前进后才能恢复有效转向。 |
| [7 · v55](v55/dev_v55.md) | 旋转捕食者初始速度方向？ | 四个已测角点中，180° 相对 0° 平均下降 **3.108 点**，rep2 下降 7.14 点。该条件 PPO−HOLD 仍为 15.13 点；不构成连续全方向稳健性证明。 |
| [8 · v56](v56/dev_v56.md) | 捕食者初速 ×0.75/×1/×1.25？ | PPO 聚合差值为 **−0.208/+0.286 点**；快速条件相对 HOLD 的优势变化区间跨零。结论限于这个 post-reset 初速范围，不是全程速度无关。 |
| [9 · v57](v57/dev_v57.md) | 训练时随机化鱼的初速？ | 三条件均衡差值 **−0.2575 点，CI [−0.7755,+0.220]**，未检出整体收益；半速有探索性负向区间。不能解释成等效、无害或机制已被排除。 |
| [10 · v58](v58/dev_v58.md) | 在未见场景上确认候选方案？ | 同六个冻结模型、64 个新场景：组合扰动差值 **+0.3201 点，CI [−0.2443,+0.9494]**，仅一对模型为正，未达替换门槛。正常条件通过预声明工程容忍度检查，仍保留标称初速训练。 |

第2轮首批试验曾因每次 reset 重用 worker seed 而反复看到相同初态。该批不作为正式结论，修复并补充真实自动 reset 测试后重跑六次训练；它不是额外的一轮科研结果。

## 当前推荐的训练与评估入口

继续使用固定焦点身份、11 维局部输入、连续环境随机流和存活/死亡奖励；在当前方案下保留 500 步 timeout bootstrap、确定性推理与标称初速训练。训练入口和完整命令见 [v50](v50/dev_v50.md)，最后的模型确认见 [v58](v58/dev_v58.md)。这是一套经过当前对照检验的工程基线，不是全局最优结论。

后续实验应在优化器更新后保存检查点并记录实际更新数；用独立场景集选择阶段，在读取报告集前记录入选模型及其 hash。历史例外不抹去，例如 v49 的阶段选择仍只能作为描述性分析。区间通常条件在固定模型上，不包括重新训练和选择过程的总体不确定性。

公开仓库保留源码、配置、数值记录与复现方法，未随这些提交分发模型 ZIP。重新训练可以生成权重，但不保证逐位相同；直接执行冻结模型评测还需要对应本地 checkpoint。

## 下一步：诊断动作响应为什么没有转化为收益

第4轮的同观测检查表明，三个模型都会因捕食者输入而改变动作。因此，问题不是简单的“模型不读取信息”。同时，屏蔽后存活率未降低、手写规则却明显受损，提醒我们：高总体存活率不能替代对威胁响应有效性的检查。输入遮蔽不是去掉信息后的重新训练；分布外输入和行为变化也不能直接命名为某个失败机制。

下一步最值得做的是对照相同状态下 PPO 与规则的动作及后续危险接触，定位失败状态和响应时机，再决定是否调整训练采样或策略结构。若研究目标以后转为响应式追击或多鱼协作，再讨论扩展世界规则；这不是当前局部避险基准自动升级的必要条件。
