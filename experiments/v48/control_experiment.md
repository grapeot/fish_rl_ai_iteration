# 第 100 步后的控制价值：同状态分支实验

## 实验设计

本实验评估现有鱼群避障仿真中第 100 步后的持续控制价值，独立于训练实现缺陷。实验由 NumPy `default_rng(482002)` 生成 40 个新种子，每局配置 96 条鱼，执行 500 步。

前 100 步运行规则策略；在第 100 步对仿真环境全状态执行深拷贝，检查鱼群位置、速度、存活状态，捕食者位置与速度、时间步及环境 RNG。随后分支对照：

- **持续控制（continued）**：继续执行当前规则决策。
- **固定 HOLD**：此后持续下发动作 4，保持惯性运动；碰撞仍可改变速度。

对比仅在各规则轨迹内成对展开，不将 lead 与 safe_top 的第 100 步状态视作相同。在 lead 持续控制优于 HOLD 后，条件性追加探索性屏蔽分支（shielded）：在策略输入副本中屏蔽捕食者可见标识、位置、速度与距离，保留边界信息，物理环境不变。

## 结果

最终存活率使用初始 96 条鱼作为分母，第 100 步前死亡仍计入；后续死亡指第 101–500 步新增死亡。

| 策略与分支 | 最终存活率 | 每局后续死亡均值 |
| --- | ---: | ---: |
| lead continued | 0.97578 | 0.675 |
| lead HOLD | 0.76172 | 21.225 |
| lead shielded | 0.84609 | 13.125 |
| safe_top continued | 0.93307 | 0 |
| safe_top HOLD | 0.93307 | 0 |

配对差异以 episode 为单位，使用 10,000 次 bootstrap 重采样：

| 前臂减后臂 | 存活率差 | 95% 区间 | 胜 / 平 / 负 |
| --- | ---: | --- | --- |
| lead continued − HOLD | +0.21406 | [0.19714, 0.23099] | 40 / 0 / 0 |
| lead shielded − continued | −0.12969 | [−0.15365, −0.10703] | 0 / 0 / 40 |
| lead shielded − HOLD | +0.08438 | [0.05599, 0.11146] | 30 / 2 / 8 |
| safe_top continued − HOLD | 0 | [0, 0] | 0 / 40 / 0 |

条件性追加的 shielded 分支属于探索性消融，其区间为名义置信区间，不是独立确认实验。

持续控制在 lead 轨迹上有实际收益，捕食者可见信息也提供了超过单独避墙的增益。safe_top 则能在本批场景中将鱼群带入没有后续新增死亡的状态，即使之后固定 HOLD 亦未增加死亡。两者并存支持具有地理策略的局部避障任务，但不代表全局最优、永久安全或所有区域均须持续危险。

## 指标边界与来源限制

- **运动状态**：safe_top 两分支一致的是存活结果而非运动轨迹。持续控制分支仍会转向；两分支速度均值分别为 0.055817 与 0.055823，均存在低速残余运动。预设近静止阈值为速度 `<0.05`，所有分支的对应比例均为零，不能声称已测得严格停车。
- **标签含义**：`safe_park_steps` 仅代表处于目标邻域且速度 `<=0.06` 的鱼-步，阈值由归一化速度 0.03 乘以最大速度 2.0 得到，并非静止。`safe_guide_steps` 是步后状态分类，不涵盖所有制导动作，尤其不能代表目标邻域外的转向次数。
- **距离指标**：记录的最小捕食者距离排除了当步刚死亡的鱼，仅限当步幸存者，不能作为无碰撞证明或生存收益的因果分解。
- **重放范围**：记录的重放校验比较最终存活计数与死亡时间，不覆盖完整位置、速度轨迹；不能将结果一致表述为所有状态逐位复现。
- **分批运行来源**：诊断标签重算与屏蔽支分批执行，没有完整保留不可变的逐批源码快照。当前源码 hash 不能证明每一批结果均由此版本生成。阈值元数据修正与原运行 hash 分开记录；独立审阅重算了原始记录的存活统计，没有再次运行完整仿真。诊断标签不承担主存活效应的证明。

## 复现

物理机制保持不变。按 `experiments/v48/dev_v48.md` 配置环境后，从仓库根目录执行：

```bash
source experiments/v48/.venv/bin/activate
python experiments/v48/tests/test_control_probe.py
python experiments/v48/control_probe.py --episodes 40 --workers 8 --shielded auto \
  --out-dir experiments/v48/artifacts/control_probe_reproduction
```

7 项测试已运行通过。新输出目录避免覆盖 `experiments/v48/artifacts/control_probe/` 下的 200 条原始记录及其汇总。运行时间和部分诊断元数据可能随环境变化，不能将文件 hash 相同当成复现的唯一标准。
